# 연구를 배우는 법 · Learning Research 한국어판

연구를 처음 시작하는 학부생과 대학원생을 위한 안내서입니다. 연구 주제를 찾고, 아이디어를 구체화하고, 실험을 설계하고, 논문과 발표로 성과를 전달하는 과정을 다룹니다.

이 저장소는 [Sida Peng의 Learning Research](https://github.com/pengsida/learning_research)를 한국어로 옮긴 **비공식 번역본**입니다. 저장소에 포함된 문서 4개를 모두 번역했으며, 원저자의 경험과 관점을 유지했습니다.

> **현재 번역 범위:** 저장소 내부 문서 4개는 한국어로 옮겼습니다. **외부 Notion·PDF·영상의 전문 번역은 아직 완료하지 않았습니다.** 외부 링크는 원어 자료로 연결됩니다. [외부 자료 진행 현황](./docs/external/README.md)과 [한국어판 안내](./TRANSLATION.md)에서 완료 범위와 남은 작업을 확인할 수 있습니다.
>
> 아래 본문의 ‘저’와 ‘우리 연구실’은 원저자와 원저자의 연구실을 뜻합니다.

## 이 자료를 만든 이유

1. 연구실의 대학원생과 학부생이 연구를 배울 수 있도록 경험을 문서로 정리하고자 했습니다. 말로만 전해지던 노하우를 기록해, 새로 들어온 구성원이 연구를 시작하는 데 도움을 주려는 목적입니다.
2. 이러한 경험을 공개해 다른 연구실의 학생들에게도 도움이 되고자 했습니다.
3. 누구나 읽고 의견을 보탤 수 있도록 공개하면, 피드백을 바탕으로 내용을 더 나아지게 만들 수 있다고 생각했습니다.

### 읽기 전에

1. 문서만으로 제가 전하고 싶은 뜻을 충분히 설명하지 못했거나, 빠뜨린 내용이 있을 수 있습니다. 연구를 깊이 있게 배우려면 이 자료를 참고하면서 직접 시도하고, 다른 연구자들과 대화하며 익히기를 권합니다.
2. 이 자료는 [저](https://pengsida.net/)의 [연구실](https://xzhou.me/) 경험을 바탕으로 합니다. 다른 환경에 그대로 적용하기 어려운 부분도 있을 수 있습니다.
3. 원문은 계속 업데이트됩니다. Notion에서 직접 수정하는 경우에는 GitHub 커밋 이력에 변경 사항이 남지 않을 수 있습니다. **원문 README에 기재된 마지막 자료 업데이트 날짜는 2026년 6월 6일입니다.** 한국어판의 번역 기준 커밋과 작업일은 [한국어판 안내](./TRANSLATION.md)에 따로 기록했습니다.

## 뛰어난 박사과정 연구자로 성장하려면

<!-- 연구 경험을 잘 정리하려면 먼저 뛰어난 박사과정 연구자가 갖춰야 할 역량이 무엇인지 답할 수 있어야 합니다. -->

제가 생각하는 가장 중요한 역량은 **장기적인 연구 목표를 세우는 능력**입니다. 좋은 목표는 학문적으로 의미가 있고 실제로도 쓸모가 있어야 합니다. 실제 응용에서 출발해, 탐구할 가치가 있는 과학적 질문을 찾아야 한다는 뜻입니다.

목표를 정했다면 이를 이루기 위한 연구 로드맵을 구체화합니다. 박사과정 동안 쓰는 여러 편의 논문이 하나의 목표를 향하도록 하고, 각 논문에서 그 목표에 얼마나 가까워졌는지 분명하게 보여 주어야 합니다. 연구 성과를 보여 주는 데모도 최대한 인상적으로 만드는 것이 좋습니다. [박사과정 연구자의 좋은 본보기: Sebastian Starke](https://pengsida.notion.site/Sebastian-Starke-1713fe292ff1808eb33be93ea2d79ad9?pvs=4)를 참고하세요.

실제로 연구를 수행할 때는 다섯 가지 역량이 필요합니다. **중요한 연구 문제를 찾는 능력, 해결책을 제안하는 능력, 실험하는 능력, 논문을 쓰는 능력, 발표하는 능력**입니다. 각 역량에 관한 구체적인 조언은 다음 자료에서 다룹니다.

1. [연구 입문: 기초 학습부터 첫 논문까지](./getting_started_in_research.md)
2. [연구 역량을 키우는 법: 문제 찾기, 아이디어 구상, 실험, 지도교수와의 미팅](./getting_advanced_in_research.md)
3. [연구 프로젝트를 수행하는 법: 박사과정 연구자가 갖춰야 할 역량](https://pengsida.notion.site/research-project-b43507ef26d044bd888ac29f4736e116)
4. 논문 쓰기
   - [논문 쓰기를 연습하는 법](https://pengsida.notion.site/c13c7e52aab64c1a8e3576b97fcb9851)
   - [논문 작성 템플릿](https://pengsida.notion.site/c1a22465a0fa4b15a12985223916048e) — 우리 연구실에서 유용하게 사용하는 자료입니다.
   - [뛰어난 연구자들의 글쓰기 경험](https://pengsida.notion.site/74aef88b9187439fa4e301704f6eb49a)
5. [심사 의견에 답변하는 법: 리버털(rebuttal)](https://pengsida.notion.site/rebuttal-af99ce47103e4917b6a5bd1fd4b3c022)
6. [학술 발표 슬라이드를 만드는 법](https://pengsida.notion.site/slides-810f02670691444f8c94cc3d5b76dcbc)
