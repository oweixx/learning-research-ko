# 영향력 있는 연구를 위한 여섯 가지 질문

[문서 목록](./README.md) · [Notion 원문](https://pengsida.notion.site/1d13fe292ff180de91afcb7f2eb57b69)

> 범위: 외부 자료의 한국어 소개·요약.

이 자료는 후위안밍(Hu Yuanming)의 Meshy 장학금 면접 경험을 읽고 정리한 노트입니다. 외부 글의 문답 전문 대신 핵심 질문을 요약합니다.

[외부 원문](https://zhuanlan.zhihu.com/p/1893638374646079902)

논문 조사·실험·집필을 익힌 다음에는 연구가 누구에게 어떤 가치를 주는지 돌아봅니다.

| 관점 | 스스로 점검할 질문 |
| --- | --- |
| 문제의 의미 | 이 문제는 왜 중요하며, 해결되면 무엇이 달라지는가? |
| 도전 | 큰 가치가 있는 아이디어를 실행으로 옮기고 있는가? |
| 변화 | 익숙한 주제에 머무는 이유가 연구 가치인지, 단기 실적에 대한 두려움인지 구분했는가? |
| 근본적인 해결 | 기존 요소를 덧붙이는 것에서 나아가 문제의 원인을 해결하는가? |
| 협업 | 잘하는 연구자의 방식에서 배우고 함께 일할 기회를 찾는가? |
| 독립적 판단 | 지도교수나 다른 사람의 의견을 근거로 검토하고 자기 견해를 설명할 수 있는가? |

번역자 주: 원문의 유명 인물 발언과 면접 대화는 인용의 진위를 별도로 확인하지 않았습니다. 위 표는 그 내용을 연구 점검 질문으로 요약한 것입니다.
