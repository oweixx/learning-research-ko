# 발표 슬라이드 구성과 디자인 자료 안내

[문서 목록](./README.md) · [Notion 원문](https://pengsida.notion.site/f1e4f77f0f3943e39dd1210bd3fe71ea)

원문은 PPT 강의·템플릿·예제 이미지 모음입니다. 외부 강의와 디자인 파일 전체의 번역·재배포 대신, 본문에 적힌 작성 순서와 자료 구성을 한국어로 안내합니다. 다수의 예제 이미지를 전부 한글로 편집한 자료는 아닙니다.

## 원문에 제시된 작성 순서

1. **각 슬라이드의 제목과 내용을 글로 적는다.**<!-- highlight -->
2. 정보를 분류하고 불필요한 문장을 뺀다. **전체 설명과 세부 설명의 위계를 나누고 각 부분에 제목을 붙인다.**<!-- highlight -->
3. 색상 체계를 정한다.
4. 화면 배치를 설계한다.
5. 요소의 모양을 다듬는다.

## 강의 구성

| 구분 | 원문 강의의 주제 |
| --- | --- |
| 1강 | SmartArt를 고르고 도형을 다듬는 방법 |
| 2강 | 배경·주제·보조·그라데이션·글자 색 |
| 3강 | 글꼴·도형·소재 선택 |
| 4강 | 시각적 구성 요소를 조합하는 템플릿 사례 |
| 5강 | 표지: 제목 배치, 배경 이미지, 구도, 강조 도형 |
| 6강 | 긴 글을 정보 단위로 나누고 위계·배치·정렬·간격을 조정하는 방법 |
| 7~12강 | 여러 이미지, 데이터, 개인·팀 소개, 표, 시간축, 조직도 |
| 13~15강 | 업무 보고, 학술 발표, 창의적인 스타일의 실습 |

원문은 특히 긴 글을 그대로 붙이는 대신 구조화된 발표 내용으로 재구성하는 점을 강조합니다. 글꼴은 본문용과 제목용을 구분합니다. 원문의 중국어 흑체 권장은 한국어 문서에서는 목적에 맞는 고딕 계열 글꼴을 선택하는 취지로 읽을 수 있습니다.

## 원문에 등장하는 도구와 자료 위치

- [Huaban](https://huaban.com/discovery): 시각 자료 참고.
- [Adobe Color 이미지 색 추출](https://color.adobe.com/zh/create/image-gradient), [색상환](https://color.adobe.com/zh/create/color-wheel): 원문은 유사색 선택을 예로 듭니다.

- [LikeFont](https://www.likefont.com/): 글꼴 찾기.
