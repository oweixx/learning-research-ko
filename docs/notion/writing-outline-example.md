## 서론: 문단별 개요

1. 장면 재구성 문제를 소개한다. COLMAP의 성과와 방법을 설명한 다음, 바닥과 벽처럼 텍스처가 없는 영역에서 성능이 낮은 이유를 설명한다.
2. 평면을 활용하는 기존 방법을 소개한다. 처리 과정과 조정할 매개변수가 복잡하며, 평면 추정이 나쁘면 재구성도 나빠지는 문제를 설명한다.
3. NeRF·VolSDF·NeuS 계열의 객체 재구성 성과를 소개한다. 실내의 넓은 무텍스처 영역에서는 같은 영상을 설명하는 기하 구조가 여러 개 존재한다는 문제를 연결한다.
4. 의미 정보로 재구성을 돕고 재구성 과정에서 의미 정보도 개선하는 방법을 제시한다. 바닥과 벽을 검출하고 맨해튼 구조에 맞는 법선 제약을 준다. 벽의 법선은 최적화한다. 분할 오류를 고려한 의미 MLP를 두고, 다중 시점 일관성과 기하 손실로 분할 확률을 개선한다.
5. 실험을 설명한다.

## 서론: 문장별 개요

### 해결하려는 문제

1. 다중 시점 영상으로 3차원 장면을 재구성하는 일은 증강현실, 로봇, 자율주행 등의 기반이다.
2. 기존 방법은 다중 시점 스테레오로 각 영상의 깊이 맵을 추정하고 이를 합쳐 기하 구조를 만든다.
3. 성과가 뛰어나지만 실내 바닥·벽처럼 텍스처가 약한 영역은 대응점 추정이 불안정해 처리하기 어렵다.

### 평면 사전 정보를 사용하는 기존 방법

1. 이러한 문제를 줄이기 위해 평면에 관한 사전 정보를 활용하는 방법들이 있다.
2. **[작성할 내용]** 평면 정보를 어떻게 사용하는지 설명한다.
3. 평면 모델링 방식으로 삼각분할, 슈퍼픽셀, 학습 기반 평면 분할을 소개한다. 원문의 인용 자리표시자는 planar prior, tapa, 빈 인용이다.
4. 이러한 방법도 깊이 또는 평면 분할이 부정확하면 성능이 낮아질 수 있다.

### 신경망 기반 표현

1. SRN·NeRF·IDR 등은 3차원 장면을 신경망 기반 암시적 표현으로 나타내고 미분 가능한 렌더러로 영상에서 학습한다.
2. IDR은 부호 거리장과 미분 가능한 표면 렌더링을 사용한다. 복잡한 장면에서 어려움을 겪는 이유로, 표면점에서만 기울기가 전달되어 국소 최적점에 빠질 수 있다는 설명을 연결한다.
3. UNISURF·VolSDF·NeuS 등은 볼륨 렌더링으로 광선 위 여러 점에 기울기 신호를 전달한다. 추가 마스크 지도 없이 복잡한 장면을 다루는 장점으로 이어 간다.
4. 그러나 텍스처가 약한 평면 영역의 성능은 여전히 낮다는 실험 결과를 제시한다. **[작성할 내용]** 해당 실험 절 번호.
5. 특히 이런 영역에서는 **같은 관측 영상을 만드는 3차원 표현이 여러 개 존재하기 때문**<!-- highlight -->이라고 설명한다.

### 제안 방법

1. 실내 장면 재구성을 위해 기하와 의미 정보를 함께 담는 암시적 신경 표현을 제안한다.
2. **평면 영역의 의미적 속성으로 재구성의 모호성을 줄이고, 기하적 속성으로 평면 분할도 개선한다.**<!-- highlight -->
3. MLP가 공간점의 부호 거리와 색을 예측한다. 바닥·벽 분할을 이용하여 해당 영역의 거리장이 맨해튼 구조에 부합하도록 한다.
4. 분할 오류가 최적화를 잘못 이끌 수 있으므로 각 3차원 점의 의미 레이블도 예측하고 기하 손실과 함께 최적화한다.

### 부호 거리장의 볼륨 렌더링

기존 다중 시점 스테레오와 달리 암시적 신경 표현을 미분 가능한 렌더러로 학습한다. IDR·VolSDF·NeuS에서 착안하여 기하와 외관을 각각 거리장과 색장으로 표현한다.

**기하 네트워크:** 공간점 x를 부호 거리 s(x)와 기하 특징 z(x)에 대응시킨다.

```text
(z(x), s(x)) = F_s(x)
```

F_s는 MLP이다.

**색 네트워크:** 점 x, 관측 방향 d, 법선 n(x), 기하 특징 z(x)를 입력받는다.

```text
c(x) = F_c(x, d, n(x), z(x))
```

법선은 x에서 부호 거리의 기울기로 구한다.

**영상으로 학습하는 과정:**

1. 영상 픽셀의 카메라 광선에서 N개 점을 샘플링한다.
2. 각 점의 부호 거리와 색을 예측한다.
3. **[작성할 내용]** 수식 1로 부호 거리를 밀도로 변환한다.
4. **[작성할 내용]** 볼륨 렌더링 식으로 픽셀 색을 계산한다.
5. **[작성할 내용]** 영상 손실을 설명한다.

**깊이 지도를 추가하는 이유:**

영상 손실만 쓰면 그림 1(a)처럼 기하가 부정확할 수 있다. 관측 방향에 의존하는 색 네트워크가 잘못된 기하로도 영상을 설명할 수 있기 때문이다. 반면 다중 시점 스테레오는 복원이 불완전하더라도 얻어진 기하 자체는 정확하다는 초안의 관점을 제시한다.

COLMAP 등에서 얻은 깊이 맵 D로 렌더링 깊이 D_hat을 지도한다. **[작성할 내용]** 깊이 손실식과 인용. 개선은 있지만 원래 깊이 맵이 무텍스처 평면 영역에서 불완전하므로 그림 1(b)의 한계가 남는다.

### 의미 정보로 안내하는 장면 재구성

1. 텍스처가 없는 평면 영역은 대체로 바닥과 벽에 있다는 관찰에서 시작한다.
2. 맨해튼 구조를 가정하면 실내의 주요 방향은 세 축에 정렬된다. 바닥은 수평이고 벽은 바닥에 수직이며 주요 벽 방향도 직교한다.
3. 2차원 의미 분할 네트워크로 바닥·벽 영역을 찾는다.
4. 평면 위 표면점의 법선이 일정한 방향을 따르도록 손실을 준다.
5. 벽에는 학습 가능한 기준 법선 n_w를 둔다. 벽 표면의 법선 n'_w가 기준 법선과 평행하거나 수직이 되도록 한다. n'_w는 거리장의 기울기로 계산한다. **[작성할 내용]** 손실식.
6. n_w는 무작위로 초기화하고 네트워크와 함께 최적화한다. 원문은 실험에서 실제 법선으로 안정적으로 수렴했다고 설명한다.
7. 바닥의 기준 법선은 z축 방향인 (0, 0, 1)로 두며 바닥 표면 법선 n'_f와 비교한다. **[작성할 내용]** 법선 손실식.
8. 바닥의 표면점 높이가 같도록 추가 제약을 준다. p_z는 점 p의 z성분, h는 학습 가능한 바닥 높이이다. **[작성할 내용]** 높이 손실식.
9. 다중 시점 스테레오의 바닥 점군을 군집화해 h를 초기화하고 모델과 함께 최적화한다. 법선·높이 손실을 가중치 lambda_h로 결합한다. **[작성할 내용]** 최종 바닥 손실식.

**이 가정은 모든 실내 공간에 성립하는 사실이 아니라 해당 방법의 모델링 가정입니다.**<!-- highlight -->

### 의미 정보와 기하의 공동 최적화

바닥·벽의 기하 제약은 도움이 되지만, 2차원 분할이 틀리면 그림 1(c)처럼 재구성도 잘못될 수 있다. 따라서 입력 의미 정보를 장면의 기하·외관과 함께 개선한다.

1. Semantic NeRF에서 착안해 공간점마다 세 종류의 의미 로짓을 예측한다.
2. 로짓에 softmax를 적용하면 바닥·벽·배경의 확률을 얻는다. 원문은 이 로짓에도 s(x), 네트워크에도 F_s를 사용하므로 앞의 거리장 표기와 충돌한다. 실제 논문에서는 기호를 구별해야 한다.
3. 로짓을 볼륨 렌더링으로 영상 공간에 투영하고, 픽셀 로짓 S_hat에 softmax를 적용해 클래스 확률 p_hat을 얻는다. **[작성할 내용]** 로짓 렌더링 식.
4. 바닥·벽의 예측 확률을 기하 손실의 가중치로 사용한다.

```text
L_joint = p_hat_f * L_f + p_hat_w * L_w
```

p_hat_f와 p_hat_w는 각각 바닥·벽 확률이다. 원문의 설명에 따르면 올바른 바닥 분할에서는 L_f를 줄이기 쉽다. 잘못된 분할 때문에 L_f가 학습 중 불안정하면 p_hat_f를 줄여 잘못된 지도의 영향을 완화할 수 있다.

안정적인 최적화를 위해 입력 의미 분할로도 예측 의미를 지도한다. **[작성할 내용]** 해당 손실식. p_k(r)는 입력 확률이고 K는 의미 범주의 수이다. 원문은 한 영역이 다수의 시점에서 올바르게 분할된다는 가정 아래, 3차원 공간에서 의미 정보를 학습하면 다중 시점 일관성을 활용해 입력 분할을 개선할 수 있다고 설명한다.
