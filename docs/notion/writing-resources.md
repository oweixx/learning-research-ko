# 논문 쓰기와 글의 흐름을 배우는 자료

[문서 목록](./README.md) · [Notion 원문](https://pengsida.notion.site/74aef88b9187439fa4e301704f6eb49a)

> 범위: 외부 자료의 한국어 소개·요약.

원문은 논문 작성 자료와 발췌 이미지를 모은 목록입니다. 아래는 자료를 찾고 읽기 위한 한국어 안내이며 책·PDF 전체의 번역본은 아닙니다.

| 자료 | 읽을 때 살펴볼 내용 |
| --- | --- |
| Bill Freeman의 논문 작성 경험 | 독자가 문제의 중요성을 이해하도록 설명하고, 기존 해법의 한계와 제안 방법의 차이를 연결하는 방식 |
| SIGGRAPH 논문 위원장들의 작성 조언 | 학술 논문을 준비하고 전달하는 방식에 관한 첨부 PDF |
| Joshua Schimel의 *Writing Science* | 문단의 중심 주제를 유지하고 문장 사이에서 정보를 자연스럽게 이어 가는 방법 |
| *Does my writing flow?* | 문장과 문단의 연결을 점검하기 위한 첨부 자료 |

원문 이미지 두 장은 Freeman의 서술 순서와 *Writing Science*의 “Flow” 장 도입부입니다. 핵심은 독자가 한 문장에서 다음 문장으로 넘어갈 이유를 만들고, 문단 안의 문장들이 같은 목적에 기여하게 하는 것입니다.

첨부 파일은 원문 페이지에서 확인하세요. 이 저장소는 외부 책의 PDF나 강의 파일을 복제하여 배포하지 않습니다.
