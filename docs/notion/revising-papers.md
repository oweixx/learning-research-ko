# 논문 고쳐 쓰기: 구성과 문장 연결

[문서 목록](./README.md) · [Notion 원문](https://pengsida.notion.site/1293fe292ff180bfa5deeed526821d78)

좋은 논문은 여러 차례 고쳐 쓰면서 완성됩니다. 초록, 서론, 방법 절뿐 아니라 한 문단에도 다음 과정을 적용할 수 있습니다.

## 문장보다 먼저 구성을 고치기

1. **구조 추출:** 작성한 문장을 읽고 핵심 내용을 개요로 바꿉니다.
2. **개요 분석:** 전달하려던 내용이 빠짐없이 들어 있는지, 전개가 자연스러운지 확인합니다.
3. **개요 수정:** 빠진 설명과 논리의 빈틈을 보완합니다.
4. **문장 작성:** 수정한 개요를 실제 논문 문장으로 다시 풀어 씁니다.

## 예시: 가우시안 계층 구조 설명

원문 초안의 뜻은 다음과 같습니다. 인용 자리표시는 아직 채워지지 않은 초안입니다.

> Hier GS, LoG, OctreeGS에서 착안하여 장면을 가우시안 프리미티브 기반 표현 G(v, t, μ, R, S, o, SH)로 모델링한다. 프리미티브는 L단계의 트리 계층으로 구성한다. 상위 단계는 시각적 품질이 거칠지만 효율이 높고, 하위 단계는 그 반대다. 상위 노드의 프리미티브는 하위 노드를 병합해 만든다. 구체적으로 l단계의 평균 μ, 회전 R, 크기 S, 불투명도 o, 구면 조화 함수 계수를 보간하여 l+1단계의 속성을 얻는다. 카메라 시점에 따라 렌더링할 노드를 선택하고 추적 정보로 노드의 속도를 수동 설정한다.

이를 개요로 바꾸면 다음 다섯 항목이 됩니다.

1. 가우시안 프리미티브로 장면을 표현한다.
2. 품질과 효율을 조절할 수 있는 트리 계층을 만든다.
3. 하위 프리미티브를 병합해 상위를 구성한다.
4. 속성 보간으로 인접 단계 사이의 값을 계산한다.
5. 카메라 시점에 맞춰 노드를 선택한다.

이 설명이 전달해야 하는 것은 **계층을 어떻게 설계했는지**와 **왜 그렇게 설계했는지**입니다. 현재 개요는 구체적인 설계가 부족하고, 설계 동기를 설명하지 않습니다.

원문의 첫 번째 AI 피드백 이미지는 표현 방식 → 계층 → 병합 → 보간 → 시점별 선택의 순서를 검토합니다. 구조 자체는 이어지지만, 계층화와 병합이 연산량을 어떻게 줄이는지, 시점별 선택이 왜 필요한지 설명을 보충하라고 제안합니다. 단계 사이의 연결 문장을 넣고 독자의 배경지식에 맞게 용어를 풀어 쓰는 것도 제안합니다.

작성자는 이 분석으로 개요를 개선한 뒤 영어 문장으로 옮기도록 안내합니다. 원문에는 최종 수정 문단이 없어 여기서 새 결과를 만들어 넣지 않았습니다.

## 문장 사이의 흐름 점검하기

서로 이어지는 두 문장마다 확인합니다.

- 두 번째 문장이 첫 번째 문장의 내용을 이어받는가?
- 다른 내용으로 옮겨 간다면 전환을 설명했는가?
- 새 용어가 갑자기 등장하지 않는가?

예시의 마지막 두 문장은 “속성을 보간한다”에서 곧바로 “시점별 노드를 고르고 속도를 설정한다”로 넘어갑니다. 두 번째 AI 피드백 이미지는 다음 문제를 지적합니다.

| 문제 | 수정 방향 |
| --- | --- |
| 보간 속성을 한꺼번에 나열해 정보가 많음 | 필요한 정보 단위로 나누기 |
| 보간에서 노드 선택으로 주제가 갑자기 바뀜 | 앞 단계와 다음 단계의 관계 설명 |
| 전환 문장이 없음 | 보간 이후 무엇을 하는지 자연스럽게 연결 |
| 노드 선택과 속도 설정이 한 문장에 묶임 | 별도 작업이라면 각각 설명 |

AI의 피드백은 검토를 돕는 제안입니다. 문장을 매끄럽게 만들면서 알고리즘의 실제 순서나 의미를 바꾸지 않도록 저자가 확인해야 합니다.
