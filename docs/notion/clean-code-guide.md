# 클린 코드 읽기 길잡이

[문서 목록](./README.md) · [Notion 원문](https://pengsida.notion.site/1053fe292ff180b59bbfe55c0961a796)

> 범위: 외부 자료의 한국어 소개·요약.

원문은 [SegmentFault의 클린 코드 정리 글](https://segmentfault.com/a/1190000019565037)을 발췌한 자료입니다. 여기서는 주제를 찾기 위한 한국어 길잡이를 제공합니다. 책이나 재수록 글 전체의 번역본은 아닙니다.

| 주제 | 점검할 내용 |
| --- | --- |
| 이름과 함수 | 의도가 드러나는 이름, 한 가지 책임, 이해하기 쉬운 인자 |
| 주석과 형식 | 코드가 설명하지 못하는 이유를 기록하고 읽는 흐름을 일정하게 유지 |
| 객체와 오류 | 데이터와 책임의 경계, 예외 처리의 일관성 |
| 외부 코드와 테스트 | 의존성의 경계, 변경을 확인할 수 있는 테스트 |
| 클래스와 시스템 | 응집도, 결합도, 관심사의 분리 |
| 점진적인 설계와 동시성 | 작은 개선의 반복, 공유 상태와 실행 순서의 복잡성 |

연구 코드에서도 결과를 다시 실행하고 변경의 영향을 추적할 수 있어야 합니다. 구체적인 규칙은 언어와 프로젝트의 조건에 맞춰 판단하세요.

함께 읽기: [연구 코드 읽기](./reading-research-code.md), [디버깅의 아홉 가지 원칙](./debugging-guide.md).
