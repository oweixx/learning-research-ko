# AI를 활용한 영어 논문 작성

[문서 목록](./README.md) · [Notion 원문](https://pengsida.notion.site/1143fe292ff180feb5d0fe76d05e085b)

핵심은 먼저 전달할 내용을 정하고, **각 문장에 무엇을 쓸지 알 정도로 개요를 구체화한 뒤**<!-- highlight --> AI의 도움을 받는 것입니다.

[서론 작성 전체 시연](https://www.bilibili.com/video/BV1jdxDeZEtq) · [문단 작성 시연](https://www.bilibili.com/video/BV1PP4Le6EcW) · [문장 작성 시연](https://www.bilibili.com/video/BV1pkxDeqE1t)

영상은 한국어 제목과 링크로 제공합니다. 아래에는 공개 본문과 첨부 이미지 17장의 학습 내용을 옮겼습니다.

## 큰 구성에서 문장까지

| 수준 | 정할 내용 |
| --- | --- |
| 절 | 초록·서론·관련 연구·방법·실험에서 각각 무엇을 설명할지 |
| 하위 절 | 특히 방법과 실험의 세부 항목 |
| 문단 | **한 문단이 전달할 중심 정보 하나와 문단 사이의 연결**<!-- highlight --> |
| 문장 | 각 문장의 내용, 앞뒤 관계, 빠진 설명 |

절 → 하위 절 → 문단 → 문장 순서로 세분화합니다. 원문은 방법과 실험에 주로 하위 절이 있다고 설명하지만 모든 논문에 적용되는 형식 규칙은 아닙니다.

[실제 논문 개요 예시](./writing-outline-example.md)도 함께 읽어 보세요.

## 문단을 작성하는 과정

1. 서론 전체의 개요를 정합니다.
2. 한 문단 안의 문장별 내용을 초안으로 적습니다.
3. 그 내용에 따라 Copilot으로 영어 문장을 작성합니다.
4. **실제로 문장을 쓰면서 문단의 개요를 계속 고칩니다.**<!-- highlight -->

### 이미지 속 서론 개요

예시는 여러 종류의 결함을 다루는 일반적인 형상 복원 연구입니다. 아래는 원문 초안의 구성이며 기술적 성능을 별도로 검증한 주장은 아닙니다.

1. **문제와 응용:** 형상 복원을 정의하고, 손상된 형상을 고치는 일이 어디에 쓰이는지 설명한다.
2. **기존 방법의 한계:** 일부 결함만 처리하는 방법은 여러 결함이 섞인 실제 입력에 대응하기 어렵다. 다룰 수 있는 데이터가 제한된다는 기술적 관점도 설명한다.
3. **새 과제 설정:** 다양한 결함을 함께 다루는 일반적인 복원 문제를 제안한다. 활용성과 데이터 범위의 이점을 실험으로 뒷받침한다.
4. **방법:** 데이터·모델·학습 전략을 소개한다.
5. **결과:** 실험 결과를 제시한다.

### 첫 문단을 다섯 차례 다듬은 과정

| 버전 | 개요의 변화 |
| --- | --- |
| 1 | 형상 복원의 정의 → 응용 → 결함이 생기는 원인 |
| 2 | 정의와 응용을 한 문장으로 합치고, 결함의 원인을 다음 문장으로 분리 |
| 3 | 결함의 원인이 다양하므로 완성·초해상도·잡음 제거 등 복원 목표도 다양하다는 설명 추가 |
| 4 | 목표가 다르면 필요한 모델의 능력도 다르다는 내용을 별도 문장으로 분리 |
| 5 | 입력 결함 유형도 다르므로 하나의 일반 모델을 설계하기 어렵다는 연결을 보충 |

이미지의 문장 뜻을 이어 읽으면 다음과 같습니다.

> 손상된 형상을 완전한 형상으로 복원하는 일은 가상현실, 로봇, 콘텐츠 생성 등에 쓰인다. 결함은 깊이 센서의 잡음, 불안정한 3차원 재구성, 기하 표현의 한계 등 다양한 원인에서 생긴다. 따라서 복원에는 형상 완성, 초해상도, 잡음 제거처럼 여러 목표가 있다. 겉으로는 서로 다른 모델 능력과 입력 처리가 필요해 보이므로, 이를 통합하는 일반 모델을 만드는 일이 어렵다.

초기 버전에는 제한된 신호 샘플링 주파수도 결함의 원인으로 등장하지만 이후 화면에서는 빠집니다. 이처럼 예시는 한 번에 완성된 문장을 보여 주기보다 내용을 더하고 나누며 전개를 다듬는 과정을 보여 줍니다.

## 문장을 작성하는 과정

1. 한 문장이 전달할 내용을 적습니다.
2. Copilot으로 초안을 만듭니다.
3. 단어와 표현이 정확한지 GPT의 도움을 받아 검토합니다.
4. **AI가 제안한 문장을 직접 다시 다듬습니다.**<!-- highlight -->
5. 필요하면 문장별 개요도 수정합니다.

### 모국어와 영어를 함께 사용하기

원문은 중국어와 영어를 섞어 의도를 설명하는 예시를 사용합니다. 아래 질문은 같은 뜻을 한국어로 옮겼습니다.

- “물체의 회전은 세 매개변수로, 물체 사이의 가림은 z-buffering으로 표현할 수 있지만 2차원 표현에서는 복잡해진다는 뜻이 잘 드러나도록 영어 문장을 다듬어 줘.”
- “영상 속 여러 물체의 3차원 움직임을 제어하여 실제 공간에서의 움직임을 재현한다는 연구 목표를 자연스럽게 표현해 줘.”

화면의 AI는 올바른 용어, 자연스러운 영어, 구체적인 설명을 제안합니다. 이는 문장 교정의 사례이며, **기술적 주장의 옳고 그름까지 보증하지 않습니다.**<!-- highlight -->

### 단어 선택을 확인하기

이미지에서는 “shape defectiveness가 적절한 표현인가?”라고 묻고, 다음과 같은 대안을 받습니다.

| 표현 | 이미지 속 설명의 뜻 |
| --- | --- |
| shape distortion | 형상의 왜곡이나 변형 |
| deformity | 비정상적인 형상 |
| irregularity | 불규칙성이나 비대칭 |
| malformation | 형성 과정의 이상을 나타내는 표현 |
| imperfection | 불완전함이나 결함 |

이후 defect가 명사인지, shape defect와 shape defects 중 어느 쪽을 쓸지 다시 묻습니다. 화면의 답변은 단일 결함과 여러 결함을 구분하고 문맥에 맞게 선택하라고 설명합니다. defect는 명사 외의 용법도 있으므로 단어 하나를 고정된 번역으로 외우기보다 문장 안에서 확인해야 합니다. 마지막 예문은 화면 아래에서 잘려 있어 보이는 부분만 반영했습니다.

### 한 문장에 두 주장을 넣지 않기

원래 메모는 “복원 목표가 다양하다”와 “각 목표에 다른 모델 능력이 필요하다”를 묶었습니다. 수정본은 이를 두 문장으로 나눕니다. 영어 표현을 매끄럽게 만드는 동안 무엇을 어느 문장에서 말할지도 함께 개선하는 사례입니다.
