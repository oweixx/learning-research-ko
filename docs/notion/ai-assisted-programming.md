# AI와 함께 코딩할 때 필요한 역량

<!-- editorial:summary -->
**세 줄로 먼저 읽기 · 한국어판 요약**

- AI에 코드를 맡기기 전에 목표와 핵심 조건을 파악하고 전체 구조를 설계합니다.
- 모듈의 연결과 데이터 흐름을 이해하고 의도를 정확하게 설명합니다.
- 생성된 코드가 맞는지 설명하고 검증하는 능력을 계속 기릅니다.
<!-- /editorial:summary -->

원문 확인일: 2026년 11월 4일. 별도 표시가 없는 조언은 원저자의 견해입니다.

원문은 바이브 코딩 시대에도 개발자에게 다음 네 가지 역량이 필요하다고 설명합니다.

1. **본질적인 목표를 파악하는 능력:** 코드로 무엇을 이루려는지 분명히 하고, 그 목표에 필요한 핵심 조건을 거꾸로 짚어 전체 구조를 설계합니다. [제1원리 사고](./first-principles.md)와 연결됩니다.
2. **구조를 설계하고 전체를 파악하는 능력:** 추상적인 알고리즘을 구체적인 모듈로 나누고, 적절한 인터페이스로 연결하며, **코드 전체의 데이터 흐름을 관리합니다.**<!-- highlight -->
3. **명확하게 설명하는 능력:** 전체 구조를 정확하고 간결한 언어로 표현해 AI가 의도를 잘 이해하도록 합니다.
4. **예리하게 디버깅하는 능력:** AI가 만든 코드에 문제가 생기면 디버깅 원칙에 따라 검증 실험을 설계하고, AI의 도움을 받아 원인을 찾아냅니다.

## 첨부 사례의 요지

외부 게시글의 이미지에서는 AI가 작성한 코드의 데이터 흐름이나 중간 변수를 설명하지 못한 학생의 사례를 소개합니다. 결과만 확인해서는 구현이 논문의 가정과 맞는지 판단하기 어렵다는 문제 제기입니다. 두 번째 이미지의 반응들은 도구 자체보다 사용하는 사람의 이해와 검증을 강조합니다.

전문 재수록 대신 사례를 요약했습니다. 원문의 일부 반응은 학생의 적성을 단정하지만, 한 사례로 누군가의 연구 능력을 판단하는 것은 적절하지 않습니다. 여기서 얻을 수 있는 실천 항목은 **생성된 코드를 설명하고 검증할 수 있는가**<!-- highlight -->를 확인하는 것입니다.
