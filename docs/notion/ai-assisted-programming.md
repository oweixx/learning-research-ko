# AI와 함께 코딩할 때 필요한 역량

[연구 가이드 목록](./README.md) · [한국어판 처음으로](../../README.md)

원문: [공개 Notion](https://pengsida.notion.site/37a3fe292ff180e18ffec36ece8a7818) · [Sida Peng의 Learning Research](https://github.com/pengsida/learning_research)

원문 확인일: 2026년 11월 4일. 별도 표시가 없는 조언은 원저자의 견해입니다.

원문은 바이브 코딩 시대에도 개발자에게 다음 네 가지 역량이 필요하다고 설명합니다.

1. **본질적인 목표를 파악하는 능력:** 코드로 무엇을 이루려는지 분명히 하고, 그 목표에 필요한 핵심 조건을 거꾸로 짚어 전체 구조를 설계합니다. [제1원리 사고](./first-principles.md)와 연결됩니다.
2. **구조를 설계하고 전체를 파악하는 능력:** 추상적인 알고리즘을 구체적인 모듈로 나누고, 적절한 인터페이스로 연결하며, 코드 전체의 데이터 흐름을 관리합니다.
3. **명확하게 설명하는 능력:** 전체 구조를 정확하고 간결한 언어로 표현해 AI가 의도를 잘 이해하도록 합니다.
4. **예리하게 디버깅하는 능력:** AI가 만든 코드에 문제가 생기면 디버깅 원칙에 따라 검증 실험을 설계하고, AI의 도움을 받아 원인을 찾아냅니다.

원문에는 반례와 그에 대한 평가를 담은 이미지 두 장이 추가로 있습니다. 이 이미지의 세부 내용은 첨부 자료 상태에서 별도로 추적합니다.
