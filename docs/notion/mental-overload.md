# 생각이 많아 지칠 때 참고할 글

[문서 목록](./README.md) · [Notion 원문](https://pengsida.notion.site/2d01e7e2a36f4860acc655c78c57cf4f)

> 범위: 외부 자료의 한국어 소개·요약.

원문은 심리 콘텐츠 제공자 Yixinli의 [Zhihu 답변](https://www.zhihu.com/question/20411759/answer/2015298724)을 재수록한 글입니다. 전문 대신 짧은 요약을 제공합니다.

글은 아직 일어나지 않은 일에 대한 걱정이 반복되는 경험을 다룹니다. 현재 하고 있는 일에 주의를 돌리고, 걱정을 글로 적어 살펴보며, 생각과 행동을 구분하는 접근을 소개합니다.

번역자 주: 원문에 나오는 뇌 에너지 소비 비율과 피로의 원인에 관한 설명은 이 한국어판에서 검증하지 않았습니다. 해당 수치를 확정된 의학 지식으로 옮기지 않았으며, 이 글은 개인의 증상을 진단하거나 치료하는 자료가 아닙니다.
