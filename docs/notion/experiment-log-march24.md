# 3월 24일 실험 기록 예시

> 첨부 이미지 25개를 직접 확인했습니다. 대부분 인체 렌더링 비교 화면이며 일부는 PSNR·학습 곡선·경과 시간 기록입니다. 그래프의 `Step`은 학습 단계, `Value`는 표시된 값, `Smoothed`는 평활화한 값, `Relative`는 경과 시간을 뜻합니다. 이미지를 실험의 독립적인 재현 결과로 검증한 것은 아니며, 시연 영상 25개는 원문에서 확인하는 참고 자료로 남겼습니다.

[문서 목록](./README.md) · [Notion 원문](https://pengsida.notion.site/492bf030bc8a48fcbe9dfd1a246678b1)

원문의 주간 실험 기록을 옮겼습니다. 결론이 확정되지 않은 가설과 빈 항목을 그대로 구분합니다. 첨부 시연 영상은 원본 실험 자료이며, 아래 시간과 결과는 작성자가 기록한 값입니다. 이 한국어판에서 실험을 재실행한 것은 아닙니다.

## 이번 주 목표

1. 다른 장면에 일반화하는 렌더링 헤드를 교체한다.
   - DTU에서 같은 구조의 헤드를 사전학습하고 교체한다.
   - 잘 작동하지 않았다. 샘플 수 또는 코드 버그를 의심한다.
2. 단일 샘플점 사용을 시도한다.
   - K-Planes와 K-Planes IBR에서 각각 4·8·48개 점으로 실험한다.
   - 깊이와 한 개 점을 이용한 결과는 매우 나빴다.

## 1. 경계가 흔들리는 현상

마스크를 넣으면 해결할 수 있지만 학습 시간과도 관련이 있었다.

| 마스크 없음 | 마스크 있음 |
| --- | --- |
| 6.3시간 결과 | 같은 행의 마스크 적용 영상 |
| 4.2시간 결과 | 같은 행의 마스크 적용 영상 |
| 2.1시간 결과 | 같은 행의 마스크 적용 영상 |

두 번째 열의 학습 시간은 원문 캡션에 별도로 적혀 있지 않습니다. 각 비교 영상은 원문 1절에 있습니다.

## 2. 일반화 가능한 렌더링 헤드 교체

### ENeRF 헤드 사전학습

1. ENeRF 렌더링 헤드가 복셀 특징에 의존하지 않도록 수정한다.
2. ENeRF 렌더링을 수정한다.

헤드를 교체하니 결과가 크게 나빠졌다. 원문은 공동 학습, 사전학습 없음, 사전학습 있음의 이미지를 나란히 제시한다.

### 가능한 원인

일반화 성능이 충분하지 않을 수 있다. 해당 장면에서 ENeRF의 성능을 확인한다.

가능한 해결책:

- 한 프레임을 빠르게 미세조정한다.
- 처음 n개 프레임을 미세조정하고, 이후에는 10프레임마다 한 번씩 미세조정한다.

### 한 프레임 미세조정 후 교체

한 프레임으로 미세조정한 헤드를 넣으니 결과가 좋아졌다. 다음 문제가 남았다.

**학습 시간이 길다.** 더 살펴볼 설정:

- 샘플링 전략: [256, 128, 48].
- 반정밀도 사용.
- 인체 마스크를 이용한 픽셀 샘플링.
- 기하 표현의 매개변수 축소: MLP를 빼거나 특징 격자를 줄이는 방법.

**카메라 경로 렌더링에 잔상이 생긴다.**

- 원문의 “렌더링 헤드 때문”이라는 가설에는 취소선이 있습니다.
- CNN + IBR 헤드에서는 왜 문제가 없는지, IBR의 학습 전략을 살펴봅니다.
- 문제가 있는 프레임만 미세조정하는 방법도 검토합니다.
- 원문의 빈 하위 항목은 추가 내용이 없습니다.

| 실험 | 원문 영상에 표시된 시간 |
| --- | --- |
| 한 프레임 미세조정 헤드를 이용한 후속 결과 | 1.5 / 3 / 4.5시간 |
| K-Planes | 1.35 / 2.7 / 4시간 |
| K-Planes IBR 공동 학습 | 2.1 / 4.2 / 6.3시간 |

시각적 결과를 확인하려면 원문 2절의 이미지와 영상을 함께 보세요. 숫자만으로 품질이나 속도의 우열을 새로 판정하지 않았습니다.

## 3. 깊이 기반 샘플링

잘 작동하지 않았다. 점의 수가 적어지면 수렴하지 못할 수 있다는 가설을 기록했다.

원문의 비교 이미지 캡션:

- 깊이 + 48개 샘플.
- 24 / 48개 샘플.
- 8개 샘플.

## 4. 공동 학습에 남은 문제

### 관찰

1. 공동 학습에서 깜빡임이 나타난다.
2. 한 프레임만 공동 학습해도 깜빡임이 나타난다.
3. 입력 소스 영상에는 뚜렷한 문제가 없어 보인다.
4. 소스 영상을 무작위로 선택하기 때문은 아닌 것으로 보인다.

원문에는 공동 학습, 단일 프레임 공동 학습, 여러 영상을 무작위로 쓰는 경우의 시연 영상이 있습니다.
