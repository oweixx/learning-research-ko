# 탐색적 실험에서 겪기 쉬운 문제

출처: [공개 Notion 원문](https://pengsida.notion.site/afe9ef02def04f6f992d0ad6070076ce) · [Sida Peng의 Learning Research](https://github.com/pengsida/learning_research)

원문 확인·번역일: 2026년 11월 4일. 별도 표시가 없는 의견과 경험은 원저자의 관점입니다.

아이디어를 구현할 때 관련 공개 코드에서 배우지 않고 모든 것을 처음부터 만들면, 이미 알려진 문제를 다시 해결하느라 많은 시간을 쓰고 지치기 쉽습니다.

하나의 방법을 실제로 작동시키려면 세부적인 구현 요령이 많이 필요합니다. 기존 연구의 코드에는 그런 시행착오의 결과가 이미 담겨 있을 수 있습니다.

이를 피하려면 관련 논문의 공개 코드를 찾아, 그 안의 구현 요령을 먼저 자세히 살펴보세요. 해당 코드에 자신의 아이디어를 직접 구현해도 좋고, 익숙한 코드 구조로 옮겨도 좋습니다. 코드를 옮기는 과정에서도 원래 구현의 세부적인 요령을 배울 수 있습니다.
