## 범위와 출처

Sida Peng의 [Learning Research](https://github.com/pengsida/learning_research)와 공개 Notion 원문을 바탕으로 한 비공식 한국어판입니다. 번역자가 덧붙인 설명은 ‘번역자 주’로 구분합니다. 원문에 링크된 모든 교재·강의·영상의 전문 번역이 끝났다는 뜻은 아닙니다.

18개 페이지의 첫 단계 연결에서 추가 Notion 문서 **44개**를 확인했습니다. 그중 실험 기록 양식은 위 목록에 포함되어 있습니다. 더 깊은 단계까지 확인한 최종 수치는 아닙니다. [원문 확인 기록](../../translation/notion-source-manifest.json)에 원문 확인일, 본문 해시, 첨부 자료 수와 추가 문서 목록을 기록합니다.
