# 목표를 이루는 과정에서 의미 찾기

[문서 목록](./README.md) · [Notion 원문](https://pengsida.notion.site/31d3fe292ff1801a97aceb84f067a0ed)

> 범위: 외부 자료의 한국어 소개·요약.

원문은 기업가 돤융핑(Duan Yongping)의 발언을 재수록한 글입니다. 발언의 최초 출처와 시점은 페이지에 표시되어 있지 않습니다. 여기서는 짧은 한국어 요약을 제공합니다.

화자는 대학 입학만을 목표로 공부하다가 합격 후 방향을 잃었던 경험을 이야기합니다. 이후에는 목표를 얻는 순간뿐 아니라 **그 목표를 향해 배우고 행동하는 과정에도 의미가 있다고**<!-- highlight --> 보게 되었다고 합니다. 투자, 가족과 보내는 시간, 비영리 조직에 대한 공부를 예로 들며 자신이 무엇을 하고 싶은지 아는 일이 중요하다고 설명합니다.

번역자 주: 특정인의 경험에 관한 글입니다. 모든 사람이 목표 달성 후 같은 감정을 느낀다는 일반 법칙이나 재무 조언으로 읽을 필요는 없습니다.
