# 논문 그림 템플릿의 공개 범위

출처: [공개 Notion 원문](https://pengsida.notion.site/2bd4d371117a45e1af4021ccc25e0515) · [Sida Peng의 Learning Research](https://github.com/pengsida/learning_research)

원문 확인·번역일: 2026년 11월 4일. 별도 표시가 없는 의견과 경험은 원저자의 관점입니다.

논문에 들어가는 그림은 연구실 고유의 스타일을 뚜렷하게 드러내기 때문에, 원저자는 이 템플릿을 **연구실 내부에서만 공유한다**<!-- highlight -->고 안내합니다.

공개 페이지에는 이 안내만 있으며 템플릿 본문은 없습니다. 따라서 이 한국어 문서는 공개된 안내문을 옮긴 것이며, 내부 템플릿을 번역하거나 확보했다는 뜻은 아닙니다.
